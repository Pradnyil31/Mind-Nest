# Routines Feature

This module will eventually contain all code related to daily routines:

- Screens and widgets for viewing/managing routines (`presentation/`).
- State management and controllers (`application/`).
- Core routine domain logic and models (`domain/`).
- Firestore access and other integrations (`infrastructure/`).

For now this folder is a scaffold; existing routine code under `lib/screens`, `lib/widgets`, `lib/services`, and `lib/providers` will be migrated here incrementally.
